<task type="auto">
  <name>Create Feedback Router</name>
  <files>backend/routers/feedback.py</files>
  <action>
    Create a new file `backend/routers/feedback.py`.
    Define a `APIRouter` instance with prefix `/feedback` and tag `Feedback`.
    Implement the following endpoints:
    - `POST /feedback/`: Creates new feedback. Requires `db: Session = Depends(get_db)` and `current_user: models.User = Depends(get_current_active_user)`. Accepts `schemas.FeedbackCreate` and returns `schemas.FeedbackOut`. Ensure `user_id` is set from `current_user.id`.
    - `GET /feedback/lesson/{lesson_id}`: Retrieves all feedback for a specific lesson. Requires `db` dependency. Returns a list of `schemas.FeedbackOut`.
    - `GET /feedback/user/{user_id}`: Retrieves all feedback given by a specific user. Requires `db` dependency. Returns a list of `schemas.FeedbackOut`.
    Ensure proper database session management and error handling (e.g., 404 for not found).
  </action>
  <verify>
    Check `backend/routers/feedback.py` for defined router and endpoints.
    Ensure endpoints use `db` and `current_user` dependencies correctly.
  </verify>
  <done>
    `backend/routers/feedback.py` contains the required feedback API endpoints.
  </done>
</task>
