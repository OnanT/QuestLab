  <name>Implement Role-Based Access Dependency</name>
  <files>backend/dependencies.py</files>
  <action>
    Open `backend/dependencies.py`.
    Add a new function `get_current_active_user_with_role(required_roles: List[str])` that takes a list of required roles.
    This function should wrap `get_current_active_user` and then check if the `current_user.role` is in the `required_roles` list.
    If the role check fails, raise an `HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Not enough permissions")`.
