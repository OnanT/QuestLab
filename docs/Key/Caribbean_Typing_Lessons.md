# Caribbean Typing Lessons — Keys of the Islands
**4 Islands · 28 Lessons · QuestLab Seed Data**

Each island has 7 lessons that follow the same skill progression but use entirely different locations, cultural context, and lesson text. Difficulty scales across lessons 1–7. All lessons are designed for the `"type": "typing"` game config.

*The Queen City of the Caribbean. Home of Alexander Hamilton, Nevis Peak, and the quietest, most beautiful beaches in the Lesser Antilles.*

---
